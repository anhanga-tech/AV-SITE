# Triage labels

The engineering skills use five canonical triage roles. Map them to the labels
that already exist in this repository:

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `status:backlog` | Maintainer still needs to evaluate the issue |
| `needs-info` | `question` | Waiting for clarification or external information |
| `ready-for-agent` | `status:ready` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `status:review` | Requires human action or review |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, apply the corresponding GitHub label from
the table instead of creating a duplicate label.
